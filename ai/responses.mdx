# Responses API

The Responses API provides a unified interface for interacting with Acme AI models.

## Endpoint

`POST /v1/responses`

## Example

```json
{
  "model": "acme-1",
  "input": "Hello, world!"
}
```

The API returns the generated response and associated metadata.
